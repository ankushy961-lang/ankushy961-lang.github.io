Questions

Questions. Answered before you ask.

What does the studio build?

We build websites, web applications, mobile applications, SaaS products, AI agents and automation, e-commerce stores, custom software and API integrations. We design, develop, launch and hand over the complete product.

How does pricing work?

You receive a written scope and a fixed quote before any work starts. We do not publish a price list, because every project is different. Tell us what you want to build and we will quote for that scope.

How long does a project take?

It depends on the scope. Before work starts, we agree milestones with you. Each milestone is a build you can open and try, so you can see how far the project has come.

Who owns the code?

You do. When the project is delivered, we hand over the release, the source code and the handover notes. The source code is yours.

How do delivery and handover work?

You test each build and ask for changes. Nothing is released without your approval. At the end, you receive the release, the source code and written handover notes.

Do you work with clients outside India?

Yes. We work remotely with clients anywhere, async by default. We are based in India, at UTC+5:30, and we work in English and Hindi. We reply within a day.

How do I start a project?

Fill in the project enquiry form on this page, or email us. Tell us what you want to build, who it is for and when you need it. We reply within a day.
